# 機能仕様

![Screenshot](https://amayegak.github.io/snaptrace-site/images/screenshot_normal_270x600.png)

## 静止画撮影

![ShotButton](https://amayegak.github.io/snaptrace-site/images/shot_button_60.png)

- スナップ動画のバッファリング中の静止画撮影指示を受け付ける
- 通常動画記録中の静止画撮影指示を受け付ける
- 静止画撮影はデバイスの最大画素サイズ固定
- 注意：プレビュー表示（ライブビュー表示・スルー画）は動画画角のアスペクト比16:9（縦姿勢時は9:16）で表示している。静止画撮影領域はプレビュー表示よりも少し広い領域となる

## スナップ動画の仕様

スナップ動画とは、SnapTrace動画(ダイジェスト動画)の元となる動画である
スナップ動画を繋ぎ合わせ合成することでSnapTrace動画を作成する

### 開始・終了点

スナップ動画の開始・終了点は以下のとおり：

- **終了点**: 静止画撮影が終了したとき
- **開始点**: 以下のうち最も遅い点
  - スナップ動画終了点の4秒前
  - 前回保存されたスナップ動画の終了点
  - バッファリングが開始された時点

### 縦動画の処理

![VerticalImage](https://amayegak.github.io/snaptrace-site/images/vertical_image.png)

- 縦動画（1080×1920）は、横動画サイズ（1920×1080）の左右の中心位置に回転せず配置
- 左右を黒く塗りつぶした映像とする
- **目的**: 繋ぎ合わせ合成時の動画フォーマット変換等を不要とするため
- **最終目的**: ダイジェスト動画（SnapTrace動画）をテレビなどの横長モニタで視聴するため

### バッファリングの中断・再開

#### 基本の振る舞い

- スナップ動画は、フロント/リアカメラ切り替え・デバイス縦横姿勢変更・動画記録停止時にバッファリングを停止し、再び新しいカメラ・姿勢でバッファリングを開始する

#### ユーザー操作

![BufferingButton](https://amayegak.github.io/snaptrace-site/images/buffering_button_125.png)
![StartBufferingButton](https://amayegak.github.io/snaptrace-site/images/start_buffering_button_125.png)

- "Buffering"ボタンが押されると、スナップ動画のバッファリングを停止する
- バッファリングが停止すると、ボタン文字列を"Start Buffering"に変更する（色も変える）
- "Start Buffering"ボタンが押されると、バッファリングを再開する

#### スナップ動画記録中

- スナップ動画記録中（バッファからの書き出し保存中）のフロントカメラ・リアカメラ切り替え、デバイス縦位置・横位置姿勢変更を受け付ける
  - このとき、バッファリングの停止・再開は行うが、バッファのクリアは行わないため書き出しているスナップ動画を途中で切るようなことはしない

#### スナップ動画記録中の静止画撮影

SnapTraceアプリ起動中、静止画はいつでも撮らせる
- 静止画撮影が終了したときをスナップ動画記録の終了点とすることは先に述べた
- 静止画撮影中にデバイス縦位置・横位置姿勢変更が発生した場合、非常に短いスナップ動画が残るか、スナップ動画が残らない可能性がある

#### スナップ動画バッファリングのプログレスバーの表示

- 表示内容
  - スナップ動画のバッファリング中、プログレスバーを表示する
  - 次の記録時に保存されるスナップ動画のバッファリング量を示す
  - 4秒のバッファリングを100%として表示する

- リセット条件
  - プログレスバーは以下のときにリセットする：
    - スナップ動画保存時
    - ロントカメラ・リアカメラ切り替え、デバイス縦位置・横位置姿勢変更、通常動画記録停止に伴うバッファリング停止・再開時

## 通常動画記録

![RecStartButton](https://amayegak.github.io/snaptrace-site/images/recstart_button_60.png)
![RecStartButton](https://amayegak.github.io/snaptrace-site/images/recstop_button_60.png)

スナップ動画とは別に、通常動画を記録することができる
- デバイス縦姿勢で通常動画記録開始したとき、縦動画を記録する
- デバイス横姿勢で通常動画記録開始したとき、横動画を記録する
- 通常動画記録中、記録時間を表示する
- 通常動画記録を開始しても、スナップ動画のバッファリングは継続する
- 通常動画記録中の静止画撮影は受け付ける
- 通常動画記録中に静止画撮影が行われたとき、通常動画とは別のスナップ動画の記録も行う
- 通常動画記録中、フロント/リアカメラ切り替えを受け付けない
- 通常動画記録中、デバイス縦位置・横位置姿勢変更が行われたとき
  - 通常動画の向きは変化しない（記録動画のアスペクト比は途中で変化しない）
  - 静止画の向きは静止画撮影時のデバイスの向きに従う
  - スナップ動画の向きは変化しない（通常動画と同じ縦横判定の動画となる）
- 通常動画記録停止時、バッファリングを停止し、再びバッファリングを開始する
  - 理由：動画記録中にデバイス縦位置・横位置姿勢変更が行われている可能性があるため

## 動画フォーマット

- **動画解像度**: FHD固定（1920×1080）
  - 通常動画、スナップ動画いずれも適用

## SnapTrace動画（一日のダイジェスト動画）作成

![CreateSnapTraceMovieButton](https://amayegak.github.io/snaptrace-site/images/create_snaptrace_movie_button_125.png)

### "Create SnapTrace Movie"ボタンでSnapTrace動画作成を開始する

### SnapTrace動画作成

- 下記のうち存在するものを繋ぎ合わせ合成する：
  - `DCIM/SnapTrace/yyyy-MM-dd/yyyyMMdd_SnapTrace.mp4`
  - `DCIM/SnapTrace/yyyy-MM-dd/snap/yyyy-MM-dd_Snap/*mp4`
- ポイント
  - 合成処理は、既存のyyyyMMdd_SnapTrace.mp4にスナップ動画を追加する処理ではない
  - 既存のyyyyMMdd_SnapTrace.mp4があっても、新たにスナップ動画が追加されたyyyyMMdd_SnapTrace.mp4を作成し直す処理である
  - 従って、**スナップ動画の数が多くなればなるほど処理時間が長くなるだけでなく、yyyyMMdd_SnapTrace.mp4も長くなればなるほど処理時間が長くなる**
  - 最も合成処理の無駄がないのは、一日の最後に一度だけSnapTrace動画合成することである

### SnapTrace動画作成中の操作

![ProcessingIcon](https://amayegak.github.io/snaptrace-site/images/processing_button_500.png)

- SnapTrace動画作成中は、"Create SnapTrace Movie"ボタンは色を変更し"Processing"と表示し、押下（タッチ）を受け付けない
  - 理由：SnapTrace動画作成処理の多重化回避
- 静止画撮影、通常動画記録操作は受け付ける
- 画像ビューワアプリ起動ボタンは受け付けない
- **注意：SnapTrace動画作成中にアプリを終了/中断した場合、SnapTrace動画を失う可能性がある**

### 作成中のプログレス表示

- SnapTrace動画作成中は、プログレスバーを表示する

### SnapTrace動画作成結果

- 合成結果のSnapTrace動画（ダイジェスト動画）は下記
  - `DCIM/SnapTrace/yyyy-MM-dd/yyyyMMdd_SnapTrace.mp4`
- 空になった`yyyy-MM-dd_Snap`フォルダは削除する

### 過去の日にちのSnapTrace動画合成

- 過去のスナップ動画で未合成のものがあれば、その日のSnapTrace動画を合成する

## 露出補正

![ExpComp](https://amayegak.github.io/snaptrace-site/images/exposure_compensation_button.png)

- デバイス縦姿勢時の画面右下に露出補正操作部を備える
- 初期状態で下向き三角の下にある円は、適正露出指示ボタンである
- 下向き三角は露出指示アイコンである
- 適正露出指示ボタンの右にあるアイコンボタンは露出を明るくするボタンである
  - 露出を明るくするボタンが押されると、少しだけ露出指示アイコンを右に移動し、露出を明るくする
    - 繰り返し押されれば大きく露出を変化させることになる
- 適正露出指示ボタンの左にあるアイコンボタンは露出を暗くするボタンである
  - 露出を暗くするボタンが押されると、少しだけ露出指示アイコンを左に移動し、露出を暗くする
    - 繰り返し押されれば大きく露出を変化させることになる
- 適正露出指示ボタンが押されると、露出指示アイコンは適正露出指示ボタンの上に移動し、露出を適正にする
- 露出補正は、プレビュー画面、静止画、スナップ動画、通常動画に反映する

## 画像ビューワアプリ起動

![ExpComp](https://amayegak.github.io/snaptrace-site/images/image_icon_36.png)

- デバイス縦姿勢時の画面左下に画像ビューワアプリ起動操作部を備える
- 初回操作時は、デバイスにインストールされている画像ビューワアプリの選択画面を表示する
  - 選択されたら、選択された画像ビューワアプリを起動する
- 2回目以降は、初回に選択された画像ビューワアプリを起動する
- 参考：初回に選択した画像ビューワアプリから別のアプリに変更したくなったとき、デフォルトで起動するアプリを変更する手段をアプリとしては備えておらず、デバイスの設定からその操作をすることは難しい可能性がある。その場合、SnapTraceを再インストールすることで画像ビューワアプリを選択し直すことができる
