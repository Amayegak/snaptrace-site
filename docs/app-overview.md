# アプリ概要

![SnapTrace icon](https://amayegak.github.io/snaptrace-site/images/snaptrace_icon_250.png)

## SnapTraceとは

SnapTraceは、カメラアプリです。静止画撮影を行うたびに、その撮影直前の動画（スナップ動画）を記録します。一日分のスナップ動画を繋ぎ合わせ合成し、一日のダイジェスト動画（SnapTrace動画）を作成することができます。

## 主な目的

- 旅行やイベントなど、一日の中で撮影した写真とともに一日のダイジェスト動画を提供し、思い出を残すのに役立てます。
  - 静止画だけでは伝わらないその場の雰囲気を、別途動画を記録する操作をすることなく、静止画撮影（Snap）とともに記録した動画から作成するSnapTrace動画（ダイジェスト動画）で残します。

## 対象ユーザー

- 旅行やイベントで思い出を残したい人
- 写真と動画を組み合わせた記録を求める人

## 機能の詳細

- アプリを起動すると、動画のバッファリングが始動します。
- 静止画撮影を行うと、その直前の動画をスナップ動画として保存します。
- Create SnapTrace Movieボタンを押すと、スナップ動画を繋ぎ合わせ合成したSnapTrace動画を作成します。
- フロントカメラとリアカメラの切り替え時および、デバイスの縦向き・横向き回転を検知してバッファリングは停止・再始動します。
- 通常動画記録手段を備えます。
- 通常動画記録中もスナップ動画のバッファリングを行います。通常動画記録中の静止画撮影も可能です。
- バッファリング中を示すボタンを押すとバッファリングは停止し、再度押すとバッファリングは再開します。
- SnapTrace動画編集機能を備えます。
