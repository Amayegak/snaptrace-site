# アプリ概要

## SnapTraceとは

SnapTraceは、カメラアプリです。静止画撮影を行うたびに、その撮影直前の動画（スナップ動画）を記録します。一日分のスナップ動画を繋ぎ合わせ合成し、一日のダイジェスト動画（SnapTrace動画）を作成することができます。

## 機能の詳細

- アプリを起動すると、動画のバッファリングが始動します。
- フロントカメラとリアカメラの切り替え時および、デバイスの縦向き・横向き回転を検知してバッファリングは再始動します。
- 通常動画記録手段を備え、通常動画記録中もスナップ動画のバッファリングを行います。
- バッファリング中を示すボタンを押すとバッファリングは停止し、再度押すとバッファリングは再開します。

## 主な目的

旅行やイベントなど、一日の記念写真とともに一日のダイジェスト動画をユーザーに提供し、思い出の記録に役立てる。静止画だけでは伝わらないその場の雰囲気を、動画を記録する操作をすることなくスナップ撮影とともに記録した動画から作成するダイジェスト動画で残す。

## 対象ユーザー

- 旅行やイベントで思い出を残したい人
- 写真と動画を組み合わせた記録を求める人
